# Sổ Vốn

Sổ theo dõi danh mục chứng khoán Việt Nam. Giá lấy từ DNSE/Entrade và Simplize. Số cổ phiếu, tiền, nợ margin và báo cáo nằm trên trình duyệt của bạn, không có tài khoản người dùng.

## Chạy

```bash
npm install
npm run dev
```

Mở http://127.0.0.1:8080.

## Telegram

1. Nhắn @BotFather, tạo bot, copy token.
2. Mở bot vừa tạo, gửi `/start`.
3. Trong app, tab Báo cáo, dán token, bấm **Lấy chat id**, rồi **Gửi thử**.

App gửi báo cáo đầu phiên, cuối phiên, biến động và tín hiệu mua bán khi cổng skill cho phép. Token chỉ lưu trên máy đang dùng.
